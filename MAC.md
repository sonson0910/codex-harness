# macOS

Use the clone/test commands in README with an existing Python 3.11+ interpreter.
The public core requires no LaunchAgent, Homebrew installer, plugin cache, credential
copy or Linux-specific runner plan. Do not overwrite your existing Codex configuration.

To adapt the workflow, ask your local coding agent:

> Read WORKFLOW.md. Compare it with the instructions I control on this Mac. Preserve
> equivalent rules, code, user edits, findings and counters. Propose the narrow source
> changes before applying them; do not add another policy layer, alter permissions,
> install dependencies or import another machine's acceptance results.

The maintainer's private machine export is intentionally not a public release asset.
Linux unit-test results do not establish live macOS integrations or future agent behavior.
